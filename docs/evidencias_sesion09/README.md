# Evidencias de la Guia Practica 09

Las imagenes de esta carpeta fueron obtenidas directamente del emulador Android
`Medium_Phone` despues de compilar e instalar el APK de la rama
`feature/expect-actual-Gutierrez`.

- `evidencia_01_listado_android.png`: muestra el precio `S/ 4.50` y el boton
  **Compartir** para Paracetamol 500 mg.

  el texto `Paracetamol 500 mg - S/ 4.50 - Stock: 120`.

No se incluyen capturas iOS porque no se ejecuto un simulador macOS/Xcode. Esa
evidencia permanece pendiente y no fue reemplazada por una imagen fabricada.
